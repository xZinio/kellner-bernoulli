# Bernoulli polynomials with integral derivatives

Carlos Kuban

This repository contains a proof of several conjectures of B. C. Kellner on the denominators of
Bernoulli polynomials, a Lean 4 formalization of it, and the computations it uses.

**Main results.** Write `s_p(n)` for the sum of the base-`p` digits of `n`.

1. For every `n > 192` there is a prime `p > √n` with `s_p(n) ≥ p`
   (Kellner 2017, Conjecture 1; Kellner 2024, Conjecture 2(i)). The exceptions `n ≤ 192` are
   1, 2, 4, 6, 10, 11, 12, 15, 16, 28, 29, 30, 35, 36, 58, 59, 60, 69, 70, 78, 79, 80, 174, 190, 191, 192.
2. The derivative `B_n'(x)` has integer coefficients if and only if
   `n ∈ {1, 2, 4, 6, 10, 12, 28, 30, 36, 60}` (Kellner 2024, Conjecture 1; OEIS A094960).
3. The denominator of `B_n(x) - B_n` equals the radical of `n + 1` if and only if
   `n ∈ {3, 5, 8, 9, 11, 27, 29, 35, 59}` (Kellner 2024, Conjecture 11; OEIS A195441).
4. The sets of `n` for which the second and third derivatives of `B_n(x)` have integer coefficients
   are the ones conjectured by Kellner (2024, Conjecture 15; OEIS A366169, A366186). The paper also
   confirms the lists in OEIS A366187 and A366188.
5. The second inequality of Kellner 2017, Conjecture 1, and a conjecture of M. Alekseyev in OEIS A094960.

The paper is [`paper/kellner.pdf`](paper/kellner.pdf) (5 pages).

**Status.** Written with the assistance of a large language model (Claude, by Anthropic), which was used
for the proof, the computations, the Lean formalization and the writing. Not yet refereed.

## The idea

If `m > √n`, then `n` has two digits in base `m`, and `s_m(n) ≥ m` fails only when `⌊n/(m−1)⌋ = ⌊n/m⌋` or
`m − 1` divides `n`. A telescoping argument shows that this happens for at most `4 + 2U²/(s+U)` of the
integers `m` in `(s, s + U]`, `s = ⌊√n⌋`. An explicit form of the prime number theorem then gives a prime
among the others, for large `n`; a computation covers the rest.

## The Lean formalization

`lake build` checks everything (about 3 minutes on a fast machine, longer on CI). There is no `sorry`, no
`native_decide` and no added axiom: every theorem depends only on `propext`, `Classical.choice` and
`Quot.sound` (run `lake env lean scripts/Axioms.lean`).

**The one external input.** The proof for large `n` uses the explicit bound

    |θ(x) − x| ≤ x / (40 log x)   for x ≥ 4·10^6,   θ(x) = Σ_{p ≤ x} log p,

which Rosser and Schoenfeld proved in 1975 (for `x ≥ 678407`, Math. Comp. 29, 243–269); Dusart (2018)
proved a stronger bound. This theorem is not in Mathlib, and formalizing it would require, among other
things, a machine-checked numerical verification of the Riemann hypothesis up to some height. It is
therefore an explicit hypothesis `h : ThetaBound` of the theorems below, and not an axiom. The
lemmas `ThetaBound.of_rosserSchoenfeld` and `ThetaBound.of_dusart` derive it from the published
statements. For `n < 1.6·10^13` the main theorem is proved without this hypothesis
(`kellner_conjecture_of_lt`).

| Result | Lean name |
|---|---|
| Main theorem | `kellner_conjecture`, `kellner_conjecture_of_lt` (no hypothesis), `kellner_exceptions` |
| `B_n'(x) ∈ ℤ[x]` | `bernoulli_derivative_intCoeffs_iff`, `bernoulli_derivative_mem_lifts_iff` |
| Second and third derivatives | `bernoulli_iterate_derivative_two`, `bernoulli_iterate_derivative_three` |
| OEIS A195441 | `oeis_A195441` (literally the statement of `OeisA195441.conjecture` in `google-deepmind/formal-conjectures`) |
| Kellner 2017, Conjecture 1 | `kellner2017` |
| Alekseyev's conjecture | `alekseyev` |

Files in `KellnerBernoulli/`:

- `Counting.lean`: the two-digit formula and the counting lemma (Lemmas 7, 8 of the paper);
- `Large.lean`: the estimate for `⌊√n⌋ ≥ 4·10^6`, from `ThetaBound`;
- `Data.lean`, `Finite.lean`, `FiniteChain.lean`, `FiniteWindow.lean`: lists of primes and their kernel check
  for `2015 ≤ n < 1.6·10^13` (the lists are generated by `scripts/gen_data.py` but need not be trusted);
- `Digits.lean`, `Criterion.lean`: denominators of `B_n(x) - B_n` and of the derivatives (Proposition 9),
  from Mathlib's von Staudt–Clausen theorem and Kummer's theorem;
- `SmallCases.lean`: kernel-checked tables for `n ≤ 2016`;
- `Main.lean`, `Corollaries.lean`: the results.

## Other computations

`verify/` contains independent C++ and Python programs for the computations in the paper, which go
further than the Lean check (up to `n < 10^18`):

    cd verify && ./run_all.sh
